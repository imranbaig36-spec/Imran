# AVD – End-User Communication: Account Not in Application Group

## Prompt Used
**Template:** End-User Comms (from Prompt-Library.md)

```
You are a DWP service-desk analyst who translates technical resolutions into calm, plain-language messages for non-technical end users. Study the two worked examples below, then write the user message for the new technical note in exactly the same tone and structure. No jargon. Under 120 words. Confirm the user's data/access is safe. State clearly what (if anything) they need to do. Return only the user message.
```

## Technical Note (Input)
AVD user couldn't connect; found their account was outside the assigned application group; added them; confirmed login.

## Generated End-User Communication (Output)
Hi — we've found and fixed the reason you couldn't connect to your virtual desktop (AVD). Your account wasn't included in the correct access group, which we've now updated. Please try logging in again — it should work as normal. All your data and settings are safe and no further action is needed from you. Sorry for the inconvenience!
